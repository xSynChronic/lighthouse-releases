If Windows says it blocked Lighthouse instead

Some PCs have Smart App Control turned on, a separate Windows check. When it blocks an app, there is no Run anyway. To install Lighthouse:

  1. Open Start and search for Windows Security.
  2. Choose App & browser control, then Smart App Control settings.
  3. Choose Off, then open the download again.

On PCs with the March 2026 Windows update, you can turn Smart App Control back on later from the same place. On older ones it stays off for good unless Windows is reset, so check with whoever sent you this link first.

The only thing Lighthouse fetches from the internet is news of an update.
